用 GitHub Pages 搭一个极简博客

2026-09-09

很多人想写博客，卡在了第一步：搭站。一上来就被 Hexo、Hugo、Jekyll、Node 版本、主题配置劝退，还没写一个字就先折腾了两天环境。

其实如果你只是想安静地写东西，一个 HTML 文件就够了。下面是完整的流程。

1. 建仓库

在 GitHub 新建一个仓库，名字随意，比如 my-blog。勾选 Public，其他都不用管。

2. 上传文件

把 index.html 传到仓库根目录。文件名必须是 index.html，这是浏览器默认访问的首页。文章多了之后可以建一个 posts/ 目录放详情页，就像这个博客一样。

3. 开启 Pages

进入仓库的 Settings → Pages，Source 选择 Deploy from a branch，分支选 main，目录选 / (root)，点保存。

等一到两分钟，访问 https://用户名.github.io/my-blog/ 就能看到你的博客了。

4. 更新内容

以后每次改动，只要把新的 HTML 推上去，GitHub 会自动重新部署。不需要任何构建步骤，也不会出现本地跑得好好的线上却挂了的情况。

一点提醒

仓库必须设为 Public，否则免费账号无法使用 Pages。另外别在页面里放任何密钥，GitHub Pages 上的所有内容都是公开的。

就这样。整个过程不到五分钟，剩下的时间，可以拿来认真写点东西了。
